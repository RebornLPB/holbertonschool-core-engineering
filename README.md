# Holberton School - Core Engineering

## 📖 About
This repository gathers the projects completed during the **Core Engineering** track at **Holberton School**. It covers the Python fundamentals, object-oriented programming, more advanced language features, and the debugging methodology used throughout the curriculum.

The goal of this track is to build solid Python foundations, understand how objects and classes work under the hood, and learn a structured approach to finding and fixing bugs.

---

## 🛠️ General Requirements & Environment
* **OS:** Ubuntu 20.04 LTS
* **Interpreter:** `python3` (version 3.8.5+)
* **Style Guide:** All Python source files strictly comply with **PEP 8** (verified via `pycodestyle`).
* **Execution:** All Python files are executable (`chmod +x`) and start with `#!/usr/bin/env python3`.

---

## 📚 Project Overview

| Directory | Core Concepts / Highlights |
| :--- | :--- |
| [`python_fundamentals`](python_fundamentals/) | Hello world, control flow, functions & modules, core data structures, exception handling |
| [`python_advanced`](python_advanced/) | File handling and other advanced language features |
| [`python_oop`](python_oop/) | Classes & the object model, inheritance, abstract base classes and mixins |
| [`debugging_strategies`](debugging_strategies/) | Reading tracebacks, `print()` debugging, `pdb`, data-flow tracing, `logging`, defensive programming |

## 🚀 Quick Start

To clone this repository and run a specific module:

```bash
git clone https://github.com/RebornLPB/holbertonschool-core-engineering.git
cd holbertonschool-core-engineering

# Navigate to a specific project directory
cd python_fundamentals/hello_world
./structured_output.py
```

### Checking PEP 8 Compliance
```bash
pycodestyle <file>.py
```
