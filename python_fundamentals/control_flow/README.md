# Python - Control Flow

## Description
This project covers Python's control flow structures: `if`/`elif`/`else` conditions and `for` loops. Each script uses conditions or loops to make decisions or repeat operations, from checking the sign of a random number to converting numbers into hexadecimal notation.

All scripts are written for **Python 3.8+** and follow the **PEP 8** style guide.

## 📝 Learning Objectives
* Use `if`, `elif`, and `else` to branch program execution.
* Use `for` loops (including nested loops) to iterate over ranges and strings.
* Format numbers with `str.format` (padding, hexadecimal notation).
* Use the `random` module to generate pseudo-random test values.

## 🛠️ Requirements & Engineering Constraints
* **OS:** Ubuntu 20.04 LTS
* **Interpreter:** `python3` (version 3.8.5+)
* **Style Guide:** 100% compliant with PEP 8 standards (verified via `pycodestyle`).
* **Execution:** All Python files are executable (`chmod +x`) and start with `#!/usr/bin/env python3`.

## 📁 File List & Tasks Directory

| File | Task Title | Description |
| :--- | :--- | :--- |
| `positive_or_negative.py` | Positive or negative | Picks a random number between -10 and 10 and prints whether it is positive, negative, or zero. |
| `last_digit.py` | Last digit | Picks a random number between -10000 and 10000 and prints its last digit, along with whether it is greater than 5, less than 6 (and not 0), or equal to 0. |
| `print_alphabt.py` | Print the alphabet in lowercase | Prints the lowercase alphabet, except for the letters `e` and `q`. |
| `print_comb2.py` | Print numbers in a specific format | Prints numbers from 0 to 99, zero-padded, separated by `, `. |
| `print_comb3.py` | Print combinations | Prints every possible combination of two digits (0-9), separated by `, `. |
| `print_hexa.py` | Print integers, and their absolute value, in hexadecimal | Prints numbers from 0 to 98 next to their hexadecimal representation. |
