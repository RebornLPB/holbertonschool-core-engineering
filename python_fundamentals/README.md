# Python - Fundamentals

## Description
This project covers the foundations of the Python language: printing structured output, control flow (conditions and loops), writing functions and organizing code into modules, using the core data structures (lists, tuples, sets, dictionaries), and handling exceptions safely.

All scripts are written for **Python 3.8+** and follow the **PEP 8** style guide.

## 📝 Learning Objectives
* Print formatted output and manipulate basic variables.
* Use `if`/`elif`/`else` and `for`/`while` loops to control program flow.
* Write reusable functions and import them from other modules (`__main__` guard, `__import__`).
* Manipulate Python's core data structures: `list`, `tuple`, `set`, `dict`.
* Catch and raise exceptions with `try`/`except`/`finally`.

## 🛠️ Requirements & Engineering Constraints
* **OS:** Ubuntu 20.04 LTS
* **Interpreter:** `python3` (version 3.8.5+)
* **Style Guide:** 100% compliant with PEP 8 standards (verified via `pycodestyle`).
* **Execution:** All Python files are executable (`chmod +x`) and start with `#!/usr/bin/env python3`.
