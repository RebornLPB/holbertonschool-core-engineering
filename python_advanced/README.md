# Python - Advanced

## Description
This project goes beyond the fundamentals and covers more advanced Python language features, starting with reading from and writing to files on disk.

All scripts are written for **Python 3.8+** and follow the **PEP 8** style guide.

## 📝 Learning Objectives
* Open files safely with the `with` statement and explicit UTF-8 encoding.
* Read a whole file's content into memory.
* Write to and append text to a file.

## 🛠️ Requirements & Engineering Constraints
* **OS:** Ubuntu 20.04 LTS
* **Interpreter:** `python3` (version 3.8.5+)
* **Style Guide:** 100% compliant with PEP 8 standards (verified via `pycodestyle`).
* **Execution:** All Python files are executable (`chmod +x`) and start with `#!/usr/bin/env python3`.
